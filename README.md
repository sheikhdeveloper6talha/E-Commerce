E-Commerce Website Project

A modern and responsive E-Commerce website built using HTML, CSS, and JavaScript. This project includes product fetching through APIs, user authentication, local storage functionality, form validation, cart management, and interactive UI features.

Features
Product Fetching using APIs
Add to Cart Functionality
Local Storage Integration
User Login & Signup System
Form Validation with Error Popups
Password Length Validation
Email Format Validation
Authentication-Based Checkout System
Users Cannot Add Products to Cart Without Login
Interactive SVG Usage
Responsive and Modern UI Design
Technologies Used
HTML5
CSS3
JavaScript
APIs
Local Storage
SVG
Authentication & Validation

The website includes a complete authentication system with signup and login functionality. Users receive popup error messages if:

Password length is less than 8 characters
Email format is incorrect
Required fields are empty

Only authenticated users can access cart and checkout features.

Purpose

The purpose of this project was to improve my frontend development skills, API handling, authentication logic, local storage management, DOM manipulation, and user experience design.
